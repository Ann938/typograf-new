# Типограф · NEW — прототип

Интерактивный прототип вариантов плашки NEW для новой кнопки «Типограф» в редакторе поста (ДВ-1…6, МВ-1…5).
Макеты и рефы — Figma, страница 48:1824. Статичный HTML/CSS/JS, без сборки.

- Локально: `python -m http.server 3800` → http://localhost:3800/#dv1
- Вариант задаётся хэшем: `#dv1`…`#dv6`, `#mv1`…`#mv5`
- Состояние «уже пользовался» — localStorage `tn:<вариант>:*`, кнопка «Показать NEW заново» сбрасывает

## Отмена Типографа и публикация (23.11.2026)

Сценарии — страница Design (48:2445) в Figma, сам макет прототип не меняет.

- Строка «Новое» появляется с первым символом в поле текста (заголовок не считается).
- Без выделения Типограф правит весь текст поста, с выделением — только фрагмент.
- Правок нет → тост «В тексте всё в порядке.» / «В выделенном тексте всё в порядке.» на 3 с.
- Есть правки → «Текст отформатирован. Отменить» — тост на 5 с (итог, раздел «Типограф» 212:15373), при наведении таймер на паузе. «Отменить» возвращает текст до последнего запуска.
- «Опубликовать пост» работает: экран «Пост опубликован»; если отмена ещё висела — она пропадает вместе с публикацией.
- ДВ: тост во всю ширину под шапкой, без крестика; МВ: под шапкой, с крестиком. «Отменить» — белый 56 % / 64 % наведение / 72 % нажатие.
- В панели прототипа «Замеры» — через сколько секунд нажали «Отменить», закрыли или опубликовали.
